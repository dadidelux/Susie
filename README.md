# Susie

**CPRAS Susie Proof of Concept**

Susie is a proof-of-concept project developed by Bryan Dadiz, demonstrating the integration of CPRAS (Continuous Process Relevance Assessment System) with a user interface. The project showcases a simple web application built using Django, providing a foundation for further development and customization.

## Features

- **Django Web Application**: A basic web interface for interacting with the CPRAS system.
- **SQLite Database**: Utilizes SQLite for lightweight database management.
- **QR Code Generation**: Implements QR code functionality for enhanced user interaction.
- **Modular Structure**: Designed with a modular approach, allowing easy extension and customization.
